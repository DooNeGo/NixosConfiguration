# Secrets (agenix)

- `secrets.nix` lists the recipients (the host key only); the encrypted files are `secrets/*.age`. Create one with `agenix -e secrets/<name>.age` from the repo root, after adding it to `secrets.nix`.
- The murmur password is such a secret, read through `environmentFile`.
- The `sing-box` config is generated by `system-config/nixos/sing-box/generate-config.py` from agenix credentials (`resolve-credential.sh`). AmneziaWG under sing-box and the Tailscale exit node: `docs/sing-box-awg.md`.
